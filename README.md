# IPBeja Beamer presentation template

This project is for slide presentations, not formal academic reports. The report template is `../mecc-report-template` and carries the IPBeja written-work layout settings.

Compile with XeLaTeX and Biber (`latexmk -xelatex main.tex`; Overleaf compiler: XeLaTeX). Replace the title, author, date and sample slide. Add your sources to `main.bib` and cite with APA author–date commands such as `\\parencite{key}`. Verify the course-specific requirements for presentations separately; the report norms' page layout and pagination rules are not applied to slides.
